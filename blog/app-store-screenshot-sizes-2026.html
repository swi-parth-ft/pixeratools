If the screenshot set is the wrong size, none of the polish matters. This page condenses the main Apple screenshot classes that matter for most iPhone, iPad, and Mac submissions, then points you to the official Apple reference before upload.

Main App Store screenshot classes to verify in 2026

These are the main device families most teams need to verify first. This list is intentionally practical: it covers the common screenshot classes you are most likely to plan around before you export the final set.

How to keep the sizing workflow from turning messy

Teams lose time when they polish screenshots before deciding the size class. Get the device family right first. Then style the exported screenshots consistently so the whole set feels deliberate.

  1. Pick the device classes you actually need to submit.
  2. Capture the raw UI at the right class or a compatible source resolution.
  3. Only after that, use Pixera to clean up spacing, backgrounds, framing, and redaction.
  4. Export the final images and verify them against Apple’s current spec one more time.

Where Pixera fits

Pixera does not replace Apple’s App Store Connect requirements. It helps when the screenshots need to look more intentional after capture: cleaner backgrounds, more balanced spacing, light callouts, and privacy-safe cleanup on Mac.
