## What The Deep Audit Challenged

- The next bottleneck is no longer basic crawl hygiene alone. Pixera needed more buyer-entry pages, not just more capability pages.
- The prior `FAQPage` schema strategy was weak for a commercial software site, so this batch removes the markup and leaves the FAQ copy visible only.
- The remaining blind spot is measurement, not page inventory. Without GA4 and Search Console scopes, the content strategy still cannot be judged against a live 14-day trend.

## Strategy Shift

- Added one use-case page and two comparison pages:
  - `/documentation-screenshots-mac/`
  - `/pixera-vs-cleanshot-x/`
  - `/pixera-vs-xnapper/`
- Expanded the homepage guide hub so the new pages inherit direct homepage visibility.
- Removed `FAQPage` JSON-LD from the homepage and all guide/comparison pages.
- Comparison pages now carry dated claims tied to 2026-04-08 so time-sensitive pricing statements are explicit instead of implied.

## Remaining Gaps

- GA4 and Search Console remain blocked by insufficient OAuth scopes in the current local auth session.
- Lemon Squeezy purchase data still does not connect the off-domain checkout to confirmed revenue inside this workspace.
- Existing guide pages still miss optional `og:locale`; that is minor compared with the measurement gap.

## Recommended Next Bets

1. Deploy and rerun the live audit so the comparison pages and docs use-case page are visible to external crawlers.
2. Fix GA4/Search Console scopes before the next run so the first impression and CTR signals on the new pages can guide the next cluster.
3. Once one buyer-entry page earns impressions, expand that branch with a tighter adjacent page instead of another broad landing page.
